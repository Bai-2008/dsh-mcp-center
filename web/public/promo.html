BEFORE / 手动时代

你原本
要做什么？

每一个 MCP，都是一次配置考试。

01 / JSON
改配置

找到文件，改 mcpServers，处理引号和缩进。

02 / KEY
找 Key

翻控制台、复制 Token，还要分清 Bearer 和原始值。

03 / CLIENTS
配 4 份

DSH、Claude、Cursor、Cline，格式还都不一样。

04 / RESTART
再重启

改完不一定生效，生效不一定连得上。
